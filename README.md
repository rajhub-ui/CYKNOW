# 🛡️ CyberFit - Citizen Cyber Resilience Platform

A Flask-based educational platform designed to protect Indian citizens from Phishing, Digital Arrest Scams, and Malicious Applications. 

## 🚀 Features
- **Adaptive Learning Paths**: A baseline survey assigns users a Beginner, Intermediate, or Advanced learning path.
- **Swipeable Learning Cards**: Bite-sized learning modules with built-in Text-to-Speech (English).
- **Interactive Simulations**: Phishing inbox simulation, Digital Arrest call simulation, and Malicious App permission quizzes.
- **Bilingual Support**: Full UI and content localization for English and Hindi.
- **Emergency Directory**: One-tap dialing to national cybercrime helplines (1930, 1909, etc.).
- **Admin Dashboard**: Analytics on user completion rates and module scores.

## 🛠️ Tech Stack
- **Backend**: Python (Flask)
- **Database**: SQLite (Self-healing schema)
- **Frontend**: HTML5, Vanilla JavaScript, Chart.js, Web Speech API
- **Authentication**: JWT + Flask Sessions
